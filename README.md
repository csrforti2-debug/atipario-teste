# atipario (versão de teste)

Protótipo de um app para famílias de pessoas atípicas registrarem terapias, escola, remédios e o dia a dia em poucos toques.

Esta é uma versão de teste: não há servidor nem conta. Tudo o que você registra fica só no seu aparelho.
Use nomes de mentira se preferir.

Projeto da disciplina de Empreendedorismo (UFPE).
